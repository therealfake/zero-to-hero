# Neural Networks: Zero to Hero — Code-Along

My notes and code following [Andrej Karpathy's "Neural Networks: Zero to Hero"](https://karpathy.ai/zero-to-hero.html) ([YouTube playlist](https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ)).

Each lecture gets its own folder under `notebooks/` with the code I wrote along with the video, plus any notes on what I learned.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```
